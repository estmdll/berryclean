# berryclean

Fast, lightweight Windows 10 & 11 system cleaner, deep uninstaller, startup manager, context menu editor, services optimizer & privacy utility.

## Download

Download the latest release from the **[Releases](../../releases/latest)** page:

- **`berryclean-setup.exe`** — Standard Windows installer (recommended)
- **`berryclean.exe`** — Standalone portable executable (no installation required)

## Highlights

- **Cleaner & Duplicate Finder** — Cleans user & system temp folders, browser & app caches, GPU shader caches, Windows Update & CBS leftovers, crash dumps, space hogs & byte-verified duplicate files with Recycle Bin undo & dry-run support.
- **BobaTreemap** — Interactive Hi-DPI storage treemap for visual disk inspection.
- **Deep Uninstaller & Leftover Hunter** — Removes Win32 & Microsoft Store apps with quiet & batch modes, automatic installer fingerprinting, & deep leftover cleanup across folders, shortcuts, registry keys & scheduled tasks (with automatic `.reg` backups).
- **Startup & Context Menu Managers** — Inspect & toggle startup programs & Explorer right-click shell extensions in milliseconds.
- **Tweaks, Services & Privacy** — Curated desktop, performance & privacy tweaks, one-click manual background service optimization (with state backup & restore), Windows Update policy switcher, DNS preset switcher, Privacy Guard & PATH Doctor.
- **RAM & Tray Monitor** — Working-set & standby-list memory maintenance with zero background UI CPU when minimized or hidden to tray.
